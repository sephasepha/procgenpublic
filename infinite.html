How it works

The world is an endless grid of sectors, each a full dungeon from the Workbench pipeline. Every sector links to a parent one step closer to the start, so they all form a single tree. Distance from the start sets the tier, so tiers rise outward and never skip. Each shared border has one contract, computed from its coordinates, that fixes where the doorway is. Both neighbours compute it independently, which means any sector can be generated on its own, in any order, and always comes out the same.

The map shows sectors near the start: colour is the tier, solid lines are tree links, dashed gold lines are loops (same tier only).

Controls

Arrow pad, swipe, or arrow keys and WASD. Run follows a corridor to the next junction. The small map in the corner is the sector tree around you. Rules checks every global rule live against the sectors currently loaded.
