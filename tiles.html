How this works

Each biome has a tileset of pixel tiles (4×4, or 8×8 for the Underdark strata) and a few example rooms built from them. The algorithm learns three things from the examples: the tiles (directional ones in all four rotations), which tile may sit next to which in each direction, and how often each appears. It then fills a floor/wall layout so that every neighbouring pair is one it saw in an example. The patch on the left is a fresh layout dressed only from these rules.

In a 3D engine nothing changes but the payload: each tile becomes a modular mesh, and the same learned neighbour rules place them.
